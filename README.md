# nickname-generator
Generate random, but good sounding, names for your everyday needs! Simple, yet effective tool if you need a nickname, project name, or anything else!

## Usage
  - press the button until you find name that suits your needs
  - Copy it 
  - press ESC to quit

## Compile with:
g++ NICKNAME-generator_SDL2.cpp -o nickname-generator `sdl2-config --cflags --libs` -lSDL2_ttf
